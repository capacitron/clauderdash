# Clauderdash — Product Context

## Product Purpose

Personal observability dashboard for Claude Code sessions. Runs locally at 127.0.0.1:7777. Ingests JSONL session logs, SQLite WAL backend, FastAPI. No accounts, no tracking, no cloud. The name: Claude + dashboard, rhymes with Balderdash — the anti-nonsense tool.

## Users

One user: the developer who built it. Arch Linux, Hyprland, dim workspace, late-night use. Glances at it between coding sessions — 2-second reads, not 20-minute studies.

## Register

product

## Scene

Developer at desk, near-dark room, monitor as the only light source. Opens the dashboard to check spend, Opus discipline, and whether recent work actually shipped. Wants instrument-panel confidence, not SaaS marketing. The interface should recede into black so the data stands out.

## Brand Personality

Spare. Precise. High-tech precision without warmth. Not a forge room — a control room. Cool alloy. The tool of someone who runs Arch Linux and measures their own discipline with military kickers like "CC · FORENSIC DIARY." Data is the only decoration.

## Strategic Principles

- Signal over noise. Every element earns its pixel.
- Glanceable first, drillable second. Summary view answers in 2 seconds.
- Cold labels. Short, noun-form, zero hedging.
- Analog precision. Gauges, not cards. Needles, not progress bars.

## Anti-References

- SaaS analytics dashboards (Mixpanel, Amplitude) — gradient cards, hero metrics, feel-good KPIs
- Dark mode developer tools with blue accent everything (VSCode dark, GitHub dark)
- Glassmorphism, neon, gradient text
- Big number + small label + gradient accent — the hero-metric template
- Anything that looks like it was generated by AI without thought
- Warm amber/forge-room aesthetic — that was the old Claude Dashboard, not Clauderdash
